# Brand assets

`icon.png` (256x256) and `icon@2x.png` (512x512) are a generic, self-drawn
mixer-fader icon — not Allen & Heath's own logo, which isn't reproduced here
for copyright reasons.

These are the same files committed under
`custom_components/allen_heath_idr/brand/`, which is what Home Assistant's
HACS brand check looks for. If you'd rather see the real manufacturer logo,
you can replace both files yourself; HACS doesn't require any particular
artwork, only that the files exist.
